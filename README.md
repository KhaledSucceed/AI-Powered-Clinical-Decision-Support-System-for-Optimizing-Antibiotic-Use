# AI-Powered Clinical Decision Support for Optimizing Antibiotic Use

> **Academic prototype — documentation reconstruction in progress.**

This repository contains an earlier AI project exploring clinical decision support related to antibiotic use. I am rebuilding the project documentation from the original artifacts before presenting model-performance, dataset, or clinical-effectiveness claims.

## Why the documentation is being rebuilt

Medical AI requires a higher evidence bar than a standard classroom classifier. A useful public case study must clearly document:

- the exact clinical decision and intended user;
- dataset provenance, inclusion/exclusion criteria, and leakage controls;
- preprocessing and validation design;
- clinically relevant metrics, calibration, and failure modes;
- subgroup / robustness checks where the data supports them;
- reproducible setup and test instructions;
- safety limitations and the role of qualified clinical oversight.

## Publication gate

I will treat this repository as a **technical/academic prototype**, not a deployed medical system, until those items are verified.

No content in this repository should be interpreted as medical advice or as a validated clinical recommendation system.
